# Sales Performance Dashboard | Power BI

## Project Overview
The Sales Performance Dashboard is a data analytics project developed using Microsoft Power BI. The purpose of this project is to analyze sales performance, identify business trends, and generate meaningful insights to support data-driven decision-making.

This dashboard provides an interactive view of sales performance across different products, locations, and time periods.

## Project Objectives
- Analyze overall sales performance.
- Identify sales trends over time.
- Compare sales across different locations.
- Understand product-wise sales performance.
- Present key performance indicators (KPIs).
- Generate actionable business insights.

## Tools & Technologies
- **Microsoft Excel:** Dataset handling and initial data preparation.
- **Microsoft Power BI:** Data visualization and dashboard development.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Calculated measures and KPI development.
- **GitHub:** Project documentation and version control.

## Dashboard Features

### Page 1: Sales Overview
- Key Performance Indicator (KPI) cards.
- Sales trend analysis using a line chart.
- Sales distribution using a donut chart.
- Overview of important sales metrics.

### Page 2: Sales Analysis
- Product-wise sales analysis using a bar chart.
- Location-wise sales performance.
- Comparative analysis of sales across different categories and regions.

## Key Business Insights
The dashboard helps users:
- Understand changes in sales performance over time.
- Identify high-performing products.
- Compare sales contributions across locations.
- Recognize patterns in sales distribution.
- Identify areas that may require business improvement.

## Business Recommendations
- Focus on products generating higher sales.
- Investigate locations with lower sales performance.
- Monitor sales trends to support future planning.
- Use performance indicators to evaluate business growth.
- Develop location-specific strategies to improve sales.
